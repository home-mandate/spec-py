# Files from the specification

Copied unchanged from [home-mandate/spec](https://github.com/home-mandate/spec) at the tag
`v0.2.0` (commit `3dbd43f79ecb91725a3fa13da0926813adaa7857`), at the same paths. Apache 2.0,
like the rest of that repository except the specification text.

- `conformance/digest-v0.json`: the digest cases of the class `evaluator`.
- `examples/` and `conformance/mandates/`: the mandate files those cases name.

The tests read them so that the digest is checked against the specification's own expected
values. Moving to a later version of the specification means copying the files of that tag.
